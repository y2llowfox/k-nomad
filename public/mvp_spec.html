K-Nomad MVP Spec

작성일: 2026-03-28 상태: Draft

1. 페이지 구조

MVP에서는 다음 2개 페이지만 유지한다.

페이지 경로 설명
홈 / 도시 리스트 + 필터 + 좋아요/싫어요
로그인 /login 이메일 로그인
회원가입 /register 이메일 회원가입

삭제 대상 페이지

  • /cities/[slug] (도시 상세)
  • /compare (도시 비교)
  • /review/[slug] (리뷰 작성)
  • /programs (워케이션 프로그램)
  • /terms, /privacy, /contact (정적 페이지)

2. 평가 시스템

  • 별점/평점 시스템 전체 삭제
  • 좋아요/싫어요 버튼만 유지
    • 좋아요 클릭 시: 아이콘 색상 변경 (빨간색) + 좋아요 수 +1
    • 싫어요 클릭 시: 아이콘 색상 변경 (파란색) + 싫어요 수 +1
    • 이미 누른 상태에서 다시 클릭 시: 토글 해제 (색상 원복 + 수 -1)
    • 좋아요 누른 상태에서 싫어요 클릭 시: 좋아요 해제 + 싫어요 활성화

3. 네비게이션

  • 유지: 로고 (홈 이동), 로그인/회원가입 버튼 (비로그인), 닉네임/로그아웃 (로그인)
  • 삭제: 홈, 비교, 워케이션 프로그램 등 다른 페이지 이동 링크 전부

4. 사이드바

  • 우측 사이드바 전체 삭제
    • 워케이션 프로그램
    • 다음 밋업
    • 지금 여행 중
    • 오늘의 추천
    • CTA 카드
    • 자세히보기 버튼

5. 필터

4개 필터만 유지한다.

필터 설명 옵션 예시
예산 월 생활비 기준 80만 이하, 80120만, 120160만, 160만 이상
지역 행정 구역 서울/경기, 강원, 충청, 전라, 경상, 제주
환경 도시 환경 특성 바다, 산/자연, 도심, 소도시
최고의 계절 방문 추천 계절 봄, 여름, 가을, 겨울

삭제 대상 필터

  • 인터넷 속도
  • KTX 연결
  • 정렬 옵션 (노마드 점수순 등)

6. 도시 카드 구조

카드에 표시할 정보를 필터 기준 key-value로 변경한다.

┌─────────────────────────────┐
│  [도시 이미지]               │
│                             │
│  도시명                      │
│  지역                        │
│                             │
│  💰 예산     80만원/월        │
│  📍 지역     전라             │
│  🌿 환경     소도시           │
│  🌸 최고의 계절  봄           │
│                             │
│  👍 42    👎 3               │
└─────────────────────────────┘

삭제 대상 카드 요소

  • 순위 (#1~#30)
  • 인터넷 속도
  • 현재 기온
  • 호버 시 6개 지표 바 차트

7. 도시 데이터

30개 도시 각각에 다음 필드를 최소 1개씩 추가한다.

필드 타입 설명
environment string[] 환경 태그: "바다", "산/자연", "도심", "소도시" 중 1개 이상
bestSeason string[] 추천 계절: "봄", "여름", "가을", "겨울" 중 1개 이상

8. 정렬

  • 기본 정렬: 좋아요 수 내림차순
  • 상단에 "총 N개 도시" 텍스트를 "도시 리스트"로 변경

9. Hero 섹션

  • 이메일 입력 + "무료로 시작하기" CTA는 유지
  • 기존 텍스트/뱃지는 유지
